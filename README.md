# Расчёт чувствительности к инсулину

React-приложение для просмотра учебных расчётов: поиск по названию, список карточек, подробности, фото и видео, нижняя навигация и переход «Далее».

Ветка приложения — `react-client`.

## Запуск

Требуются Node.js 22+ и npm. Из корня этого репозитория:

```sh
git switch react-client
npm ci
npm run dev
```

Открыть http://localhost:5173. При занятом порте:

```sh
npm run dev -- --port 5174
```

На первом экране сразу доступны три mock-карточки без бэкенда.
Нажатие «Искать» запрашивает собственный API; при недоступности API или пустом
ответе используется учебный mock. Источник данных показан над списком.

## Подключение собственного API

NestJS остаётся в отдельном
[репозитории бэкенда, ветка cookies](https://github.com/dinara323/Web-Insulin-calculation/tree/cookies).
Инструкция его запуска находится там в `README_LR4.md`. Для настоящих данных
бэкенд запускается со своими PostgreSQL, Redis и MinIO.

По умолчанию Vite проксирует `/api` на http://localhost:3000.
При другом адресе создайте локальный `.env.local` по примеру `.env.example`:

```dotenv
API_TARGET=http://localhost:3004
```

После изменения перезапустите Vite. Префикс `/api` сохраняется;
запросы используют `credentials: 'include'`. Изменять CORS в исходном бэкенде
для работы через этот прокси не требуется.

Используются только запросы чтения:

- `GET /api/services?name=...` — список с поиском;
- `GET /api/services/feed?id=...` — карточка при прямом открытии подробностей.

## Соответствие пятой лабораторной работе


| Требование | Файлы и поведение |
|---|---|
| React, TypeScript, Vite | `package.json`, `src/main.tsx` |
| Функциональные компоненты и Props | `src/components/`, `src/pages/` |
| Состояние и жизненный цикл | `useState`, `useEffect`, отмена запросов при уходе со страницы |
| Два экрана и React Router | `/` — список, `/detail/:id` — подробности |
| Общий массив карточек | `src/AppLayout.tsx`, Outlet context |
| Поиск и mock | `src/modules/mock.ts`, `src/pages/ServicesPage.tsx` |
| Дефолтное изображение | `public/DefaultImage.jpg`, `ServiceImage.tsx` |
| Нижняя панель | `TabBar.tsx`, активная вкладка, переход к первой карточке текущего массива |
| Фото и видео | `DetailPage.tsx`; видео autoplay, loop, muted, playsInline; при ошибке — фото |
| Кнопка «Далее» | Следующий элемент текущего массива; на последнем кнопка отключена |
| Собственный API | `src/modules/servicesApi.ts`, Vite proxy |
| Мобильная вёрстка | Колонка до 390 px, на узком экране 100%, панель закреплена снизу |
| Docker | `Dockerfile`, `.dockerignore`, `docker-compose.yml` |

Поиск mock выполняется по началу названия без учёта регистра. При отсутствии
совпадений возвращается весь mock, как в пункте 7.1 методички. При возврате
из подробностей сохраняются поисковая строка и найденный массив. Идентификаторы
не увеличиваются арифметически: «Далее» использует порядок массива.
